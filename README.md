# calculator

This project is a calculator that supports addition, subtraction, multiplication, and divison operators.

You can enter in any expression including any of these operations, and it will compute the answer.

The calculator includes:
- Number Buttons 0-9
- Operation Buttons '+', '-', '*', '/'
- Equals button '='
- Clear button 'C'

The skills demonstrated in this project include:
- HTML
- CSS
- JavaScript
- DOM Manipulation
- Event Listeners
- Functions
